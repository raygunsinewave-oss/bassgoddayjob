# BASSGODSDAYJOB

A bass-only wavetable synthesizer (VST3 / AU / Standalone) by **Raymond Duarte (Raygun)**, with
430 factory basses and an animated club in the middle of the UI. You're the DJ behind the decks,
and the crowd reacts in real time to the sound coming out of the synth.

- 3 wavetable oscillators (97 built-in bass tables, WAV import, editor) + a sub/noise oscillator (46 noise textures)
- 2 filters with 32 models, serial / parallel / split routing
- 4 envelopes with per-segment curves, 8 drawable LFOs with a Wobble Builder, 4 macros, 64-slot mod matrix, drag-and-drop modulation
- Mono / Legato / Poly (16 voices), portamento, MPE, microtuning (.scl / .tun), "Bass Mono Below"
- 12-slot drag-to-reorder FX rack + final limiter (13 modules)
- Visualizer / metering tab: spectrum, spectrogram, scope, goniometer, LUFS, levels, sub check, tuner, creative visualizers, phase/DC
- The club scene: audio feature extractor, crowd mood state machine and 60 crowd reactions

See [docs/USER_MANUAL.md](docs/USER_MANUAL.md) for how to use it.

## Building

Requirements: CMake 3.22+, a C++20 compiler. JUCE 8.0.4 is downloaded automatically by CMake
(or point `-DBGDJ_JUCE_PATH=/path/to/JUCE` at a local checkout).

| OS | One command | Output |
|---|---|---|
| macOS 11+ (Xcode 15+) | `scripts/build_macos.sh` | Universal (arm64 + x86_64) VST3, AU, Standalone |
| Windows 10+ (VS 2022) | `scripts\build_windows.bat` | x64 VST3, Standalone |
| Linux (dev / CI) | `scripts/build_linux.sh` | VST3, Standalone |

Each script configures, builds Release and runs the unit tests. Artefacts land in
`build/BASSGODSDAYJOB_artefacts/Release/`.

Linux needs: `libasound2-dev libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxcomposite-dev libxext-dev libfreetype-dev libfontconfig1-dev libgl1-mesa-dev`.

CMake options:

| Option | Default | Meaning |
|---|---|---|
| `BGDJ_JUCE_PATH` | empty | Use a local JUCE checkout instead of downloading 8.0.4 |
| `BGDJ_BUILD_TESTS` | `ON` | Build the `BGDJ_Tests` unit-test runner |
| `BGDJ_UPDATE_REPO` | empty | `owner/repo` that "Check for updates" queries (GitHub releases). Empty = the button says updates aren't configured |

Plugin codes: manufacturer `Rayg`, plugin `Bgdj`, bundle id `com.raygun.bassgodsdayjob`.

## Tests and validation

```bash
ctest --test-dir build -C Release --output-on-failure
```

The test runner (`Tests/`) covers: band-limiting of every wavetable mip level, stability of all 32
filter models at maximum resonance/drive, envelope timing, tempo-synced LFO rates, microtuning
parsing, the lock-free FIFOs (multi-threaded), BS.1770 loudness calibration, the full FX rack and
its limiter ceiling, voice allocation (legato / poly), mod-matrix routing, every warp mode, seed
lock reproducibility, a per-voice CPU check, all 430 presets (count per bank, unique names,
every parameter and mod routing valid, no banned words), and the crowd: 60 reactions, no
back-to-back repeats, and the spec's trigger wiring (mud, clipping, phase, boredom, walkout).

Plugin validation (done in CI on each OS):

```bash
pluginval --strictness-level 8 --validate build/BASSGODSDAYJOB_artefacts/Release/VST3/BASSGODSDAYJOB.vst3
auval -v aumu Bgdj Rayg     # macOS, after copying the .component to ~/Library/Audio/Plug-Ins/Components
```

## Installers

- **Windows:** `iscc /DArtefacts=<artefacts dir> installer\windows\BASSGODSDAYJOB.iss` (Inno Setup 6).
- **macOS:** `installer/macos/build_pkg.sh <artefacts dir> dist` builds a `.pkg` (VST3 / AU / app / manual).
  Signing and notarization kick in when these are set:
  `DEV_ID_APP`, `DEV_ID_INSTALLER`, and either `NOTARY_PROFILE` or `APPLE_ID` + `APPLE_TEAM_ID` + `APPLE_APP_PASSWORD`.
  Without them it produces an unsigned package and says so.

## CI

`.github/workflows/build.yml` builds macOS (universal), Windows (x64) and Linux, runs the unit
tests and pluginval (strictness 8), runs `auval` on macOS, and uploads the installers as
artifacts. For signed macOS builds add these repository secrets: `MACOS_CERT_P12_BASE64`,
`MACOS_CERT_PASSWORD`, `MACOS_DEV_ID_APP`, `MACOS_DEV_ID_INSTALLER`, `APPLE_ID`, `APPLE_TEAM_ID`,
`APPLE_APP_PASSWORD`.

## Factory presets

The 430 presets live in `Resources/presets/factory/<BANK>/*.bgdjpreset` (JSON) and are embedded
in the binary. They're generated by `tools/generate_presets.py` from per-bank sound-design
recipes with a fixed seed, so re-running it reproduces the same files. Names are original;
artist names, song titles and trademarks are banned (checked by the script and by the tests).

## Real-time safety

The audio thread never allocates, locks or touches files. Wavetables, LFO tables, tuning tables,
noise sets and the ducker curve are built on the message thread and handed over with an atomic
pointer swap (`RtSharedObject`), with retired objects freed later on the message thread.
Analysis audio, crowd features, UI MIDI and SFX cues cross threads through single-producer /
single-consumer FIFOs. All buffers (oversamplers for 2x-16x, comb/delay lines, FX scratch) are
sized in `prepareToPlay`. The club scene runs on its own UI timer (30-60 fps by quality).
